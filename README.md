# Interactive Digital Tree

A custom-built electronic hardware project driven by an Arduino Uno. The core concept is a "digital tree" that dynamically grows and produces heart-shaped fruits.

## How It Works
The system runs on custom C++ firmware that handles the visual display logic. When interacted with, the tree goes through a growth animation cycle. Inside each "fruit", the display reveals a hidden *Sankalpa* (a positive intention). 

## Hardware Stack
*   Arduino Uno
*   Matrix Display Modules
*   Custom wiring and enclosure

## Running the Code
Flash the `.ino` file to your Arduino Uno using the Arduino IDE or PlatformIO. Make sure to install the required display libraries mentioned in the source file before compiling.
